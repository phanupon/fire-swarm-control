# คอนโซลฝูงโดรนแนวไฟ — Firefront Swarm Console

Prototype simulation ประกอบบทความวิจัย **"โมเดลการวางเส้นทางแบบเรียลไทม์สำหรับฝูงโดรนสำรวจไฟป่าภายใต้ข้อจำกัดด้านพลังงานและสภาพแวดล้อมหมอกควันและความร้อน"**
(ภาณุภณ พสุชัยสกุล — สาขาวิชาปัญญาประดิษฐ์และนวัตกรรมธุรกิจ คณะนวัตกรรมวิทยาศาสตร์และวิศวกรรม มหาวิทยาลัยเกริก)

เว็บหน้าเดียว 100% static — ไม่มี backend ไม่มี build step ไม่เก็บข้อมูลผู้ใช้

---

## โครงสร้างไฟล์

```
.
├── index.html          ← ทั้งซิมูเลชันอยู่ในไฟล์นี้ไฟล์เดียว (HTML + CSS + JS)
├── vendor/
│   └── three.min.js    ← Three.js r128 (self-hosted, ไม่พึ่ง CDN)
├── preview.jpg         ← ภาพ og:image สำหรับแชร์ลิงก์
├── vercel.json         ← cleanUrls + cache headers
└── package.json        ← สคริปต์ dev / deploy (ไม่จำเป็นต่อการ build)
```

## Deploy ขึ้น Vercel

### วิธีที่ 1 — Vercel CLI (เร็วที่สุด)

```bash
npm i -g vercel        # ถ้ายังไม่มี
cd firefront-swarm-console
vercel login
vercel                 # deploy preview
vercel --prod          # deploy production
```

ตอบคำถามตอนตั้งค่าโปรเจกต์:

| คำถาม | ตอบ |
|---|---|
| Framework Preset | **Other** |
| Build Command | เว้นว่าง (หรือ `npm run build`) |
| Output Directory | `.` |
| Install Command | เว้นว่าง |

### วิธีที่ 2 — ลากวางบนเว็บ

บีบอัดโฟลเดอร์นี้เป็น `.zip` แล้วลากไปวางที่ https://vercel.com/new — Vercel จะ deploy ให้อัตโนมัติ

### วิธีที่ 3 — ผ่าน GitHub (แนะนำถ้าจะแก้ต่อ)

```bash
git init && git add . && git commit -m "Firefront Swarm Console prototype"
git branch -M main
git remote add origin https://github.com/<user>/firefront-swarm-console.git
git push -u origin main
```

แล้วเข้า https://vercel.com/new → Import Git Repository → เลือก repo → Framework Preset = **Other** → Deploy
ทุกครั้งที่ push จะ deploy ใหม่อัตโนมัติ

## รันในเครื่อง

```bash
npx serve .            # หรือ  python3 -m http.server 5173
```

เปิด http://localhost:5173 (เปิดไฟล์ `index.html` ตรง ๆ ด้วย `file://` ก็ได้ เพราะไม่มีการ fetch ข้ามไฟล์)

## พารามิเตอร์โมเดล (แก้ในไฟล์ `index.html`)

ค้นหาบล็อก `/* constants */` ใกล้ต้นสคริปต์

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `G` / `CELL` | 60 / 40 | ขนาดกริด และเมตรต่อเซลล์ (40 ม. = 1 ไร่/เซลล์) |
| `SPREAD_K` | 0.0085 | สัมประสิทธิ์ความน่าจะเป็นการติดไฟของเซลล์ข้างเคียง |
| `BURN_K` | 0.007 | อัตราการเผาผลาญเชื้อเพลิงต่อวินาที (กำหนดอายุการลุกไหม้ของเซลล์) |
| `CRUISE` / `AGL` | 18 ม./วิ / 95 ม. | ความเร็วเดินทาง และระดับบินเหนือพื้นดิน |
| `DRAIN` / `BATT_WH` | 0.112 %/วิ / 300 Wh | อัตราการใช้พลังงาน และความจุแบตเตอรี่ |
| `W_INFO`, `W_HAZ_C`, `W_HAZ_P`, `W_E` | 6.0 / 1.15 / 0.95 / 0.75 | น้ำหนักในฟังก์ชันเป้าหมายของ planner (ข้อมูล / อันตรายปลายทาง / อันตรายบนเส้นทาง / พลังงาน) |

ตัวแปรอื่น (จำนวนโดรน ลม อัตราลุกลาม หมอกควัน รัศมีเซ็นเซอร์ ระยะสื่อสาร เกณฑ์พลังงานสำรอง) ปรับได้จาก UI โดยตรง

## การใช้เก็บผลเข้าบทความ

1. เปิด **โมดูลประมาณการพื้นที่รุกลาม** → รันจนจบภารกิจ → กด **บันทึกผลรันปัจจุบัน**
2. ปิดโมดูลดังกล่าว (โหมด baseline) → กด **รีเซ็ต** → รันซ้ำด้วยค่าพารามิเตอร์เดิม → กด **บันทึกผลรันปัจจุบัน**
3. ตารางเปรียบเทียบทางขวาจะแสดงสองคอลัมน์ พร้อมคัดลอกเข้าหัวข้อ 4 ผลการวิจัย

> ข้อควรระบุในบทความ: ตัวเลขที่ได้มาจากโมเดลจำลองที่ยังไม่ได้สอบเทียบกับข้อมูลไฟป่าจริงหรือสเปกอากาศยานรุ่นใดรุ่นหนึ่ง ควรรายงานค่าพารามิเตอร์ที่ตั้งไว้ และรันซ้ำหลาย seed เพื่อรายงานค่าเฉลี่ย ± ส่วนเบี่ยงเบนมาตรฐาน
